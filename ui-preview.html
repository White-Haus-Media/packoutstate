One data change needed to ship this. The EVENTS array stores times as display strings ('9:00 PM – 1:00 AM'), which a calendar can't read. Each event needs two machine-readable fields — start and end in ISO form, e.g. '2026-10-29T21:00:00-04:00'. Parsing the display string instead would be guesswork, particularly for events crossing midnight.

Component 08

Form inputs New

No inputs exist on the site today. Font size is 16px minimum — anything smaller makes iOS Safari zoom on focus and yank the layout sideways. Hints sit above the field, never below.
